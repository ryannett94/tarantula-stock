Or set up one-tap updates (token)
  1. Open GitHub → new fine-grained token. Resource owner: ryannett94.
  2. Repository access: Only select repositories → tarantula-stock.
  3. Choosing the repo gives no permissions on its own – that's the "no permissions" message. Under Permissions, tap Add permissions (or open Repository permissions) and add Actions and Contents.
  4. Set Actions → Read and write. Leave Contents → Read-only. (Metadata read-only gets added automatically.)
  5. The summary should now say access to 1 repository with those permissions. Generate, copy, paste below. It's kept only in this browser.
